# LibraryApp

Консольное приложение «Библиотека» на C# и .NET 8.

Автор: Лыткин Максим Константинович.

## Запуск

Откройте `LibraryApp.sln` в Visual Studio 2022 с установленными средствами разработки .NET 8 и запустите проект сочетанием Ctrl+F5. Для запуска из терминала нужен .NET 8 SDK:

```shell
dotnet build LibraryApp.sln
dotnet run --project LibraryApp/LibraryApp.csproj
```

## Возможности

- Добавление книг и журналов с проверкой названия, автора, года, числа страниц и номера выпуска.
- Просмотр всех изданий через общий тип `LibraryItem`.
- Поиск книг по части имени автора без учёта регистра.
- Выдача и возврат книги через интерфейс `IBorrowable`; повторная выдача отклоняется.
- Получение названий книг, выпущенных после 2000 года.
- Обработка пустого ввода, неверных чисел, выхода числа за диапазон и отсутствующих записей.

При выдаче используется имя «Пользователь». Для поиска книги при выдаче или возврате
нужно ввести полное название без учёта регистра. Если названия совпадают, используется
первая добавленная книга с этим названием.

Данные хранятся в памяти до закрытия программы. При запуске библиотека пуста.
Допустимый год издания — от 0 до следующего календарного года включительно;
число страниц и номер выпуска должны быть положительными.

## Структура

- `LibraryApp/Models/LibraryItem.cs` — абстрактный базовый класс издания.
- `LibraryApp/Models/Book.cs` — книга, выдача и возврат.
- `LibraryApp/Models/Magazine.cs` — журнал с номером выпуска.
- `LibraryApp/Models/IBorrowable.cs` — контракт выдачи и возврата.
- `LibraryApp/Services/Library.cs` — коллекция изданий и LINQ-запросы.
- `LibraryApp/Program.cs` — консольное меню и обработка ввода.
