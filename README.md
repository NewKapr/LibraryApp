# LibraryApp

Консольное приложение «Библиотека» на C# и .NET 8.

Автор: Лыткин Максим Константинович.

## Запуск

Откройте `LibraryApp.sln` в Visual Studio 2022 с установленными средствами разработки .NET 8 и запустите проект сочетанием Ctrl+F5. Для запуска из терминала нужен .NET 8 SDK:

```shell
dotnet build LibraryApp.sln
dotnet run --project LibraryApp/LibraryApp.csproj
```

## Лабораторные работы

| Работа | Тема | Версия |
|---|---|---|
| 1 | Классы и объекты | `lab-1` |
| 2 | Инкапсуляция и свойства | `lab-2` |

Каждая лабораторная представлена отдельным коммитом. Для открытия предыдущей версии используйте, например, `git switch --detach lab-2`. Для возврата к последней версии — `git switch main`.
